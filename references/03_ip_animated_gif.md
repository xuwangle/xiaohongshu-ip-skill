# 阶段三：IP 形象 → 可播放透明 / 纯白 GIF 动作延展

根据选定的 IP 形象制作可播放的 GIF（表情包、开场动作、点赞/加油挂件等），**严格保持原角色的造型、比例、配色与画风**，不重新设计角色。

## 一、开始前两轮提问（已提供信息不重复）

- **第一轮**：想要什么动作、表达什么情绪？（可结合角色与 `07_表情设定.png` 给出 3–4 个建议）
- **第二轮**：
  - 构图比例：`1:1`、`3:4`、`9:16`、`16:9`
  - 景别：全身、半身、近景
  - 节奏：自然、缓慢柔和、活泼
  - 播放方式：循环、结束停留后重复、单次播放
  - 是否有指定时长或文件大小限制？

每项均支持用户回答「由你决定」，回答齐备后直接执行。

## 二、工具与参数核实（严禁虚报能力）

1. 优先按要求使用 `Seedream 5.5` 生成母图，优先使用当前环境的「母图转 GIF」工具；支持独立帧生成与合成时也可采用逐帧合成。
2. **环境实事求是**：先核实当前环境究竟有哪些图像与动图工具。如果 `Seedream 5.5` 或「母图直转 GIF 工具」不可用，**必须先如实说明现状，绝不擅自静默替换**；若在通用环境经用户同意改用 `nanobanana` + 逐帧合成（可调用本仓库 `scripts/gif_compose.py`），需在交付说明中如实标注实际使用的生图模型与合成方式，且不承诺工具不支持的精确帧时长或单帧控制。
3. 默认 `6～9` 帧（优先 `9` 帧），目标分辨率 `720P` 并保持所选比例；用显式工具参数设置帧数和尺寸，超出限制时先调帧数、再调尺寸，报错后根据原因调整，不重复提交同一报错配置。

## 三、背景规则

- **优先真透明背景**：母图使用带 Alpha 通道的 PNG，最终 GIF 保留透明区域；
- 无法可靠生成或保留透明时，**自动使用纯白 `#FFFFFF`**，无需再次询问；
- 严禁使用棋盘格图案、色键绿幕背景或新增粗黑外描边来冒充透明。

## 四、母图与连贯动作生成

1. 从输入 IP 提取 `1～2` 个核心识别特征（形状、比例、非对称配饰位置）；
2. **生成并验收母图**：起始姿态清楚、固定镜头与角色基准大小、按完整动作范围预留四周安全空白（防止裁切）；检查身份、结构、画风和空间合格后再做动画；
3. **动作描述始终以母图为依据**，用一条连贯链条表达：  
   `起始姿态 → 运动方向与支点 → 关键姿态 → 收势或回到起始附近`。
4. 动作幅度与角色保真冲突时，优先缩小动作幅度；最终交付真实可播放 `.gif` 文件（`scripts/gif_compose.py` 可用），绝不用静态图、分镜拼图或视频充当 GIF。
