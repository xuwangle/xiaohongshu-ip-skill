# 阶段二：选定 IP 形象 → 14 张「IP 品牌视觉全案」

围绕用户选定的唯一 IP 形象建立视觉展示与应用系统，**不重新设计角色**。必须实际生成完整独立图片，不能只输出文字方案，也不组装全案总览长图或拼板。

## 一、交付清单（8 个主题，共 14 张独立高清 PNG）

1. `01_品牌近景封面.png`（竖版 3:4）
2. `02_IP特征说明.png`（竖版 3:4）
3. `03_标准三视图.png`（横版 4:3，正面/侧面/背面等比例立正对齐）
4. `04_五种画风与材质延展.png`（横版 4:3，彩铅原画 / 水彩纸感 / 平面剪纸 / 软陶质感 / 毛毡质感）
5. `05_标准配色.png`（竖版 3:4，6 组平涂实色色块 + HEX 标注）
6. `06A_独立个人IP_LOGO.png`（横版 3:2，**真透明 Alpha 通道 PNG**）＋ `06B_LOGO背景.png`（LOGO 背景应用）
7. `07_表情设定.png`（竖版 3:4，3×3 共 9 种表情：开心、思考、惊讶、认真、疑惑、期待、困倦、委屈、加油）
8. `08A–08F` 六款独立自媒体封面（竖版 3:4，6 张各自独立成图）

## 二、开始前先确认

收到定稿 IP 图片后，**只询问这 1 项**（已提供则跳过不重复）：
> “你希望用什么内容制作个人 IP LOGO？可以是姓名、昵称、英文名、字母缩写或一段短文字。请提供准确内容，大小写有要求也请注明。”

等待回答后即可自主完成所有文案、版式与材质选择，不再逐页请示确认。

## 三、唯一角色基准与防崩规则

用户选定的原始 IP 图片是**唯一角色依据**，制作前先沉淀一份简洁的 `角色规范.md`，锁定：
- 身份、轮廓、身体结构与头身比例（例如约 3 头身）；
- 五官形态与相对间距、发型外轮廓与发际线位置；
- 固定服装、鞋履、配饰与**非对称细节的左右手方向**（如右腕腕表正面看在画面左侧，严禁镜像翻转）；
- 原有配色 HEX、细铅笔轮廓、彩铅纸感与轻阴影质感（无厚黑描边、无塑料高光）。

每生成一张全案图片，**必须同时参考原始基准图与同一份 `角色规范.md`**，不得只顺着上一张衍生图继续漂移；未展示的侧面与背面只做最小合理补全。

## 四、名称与输出诚实红线

- 正式名称与 LOGO 文字严格按用户输入，不擅自翻译、改写、加词，也不插入无关真实姓名（未提供名称时使用「IP 形象设计」等中性标题）；
- 不根据文件名或水印推测角色信息，不编造品牌历史、职业、年龄、性别、机构或版权归属；
- 不将透明背景 PNG 称为可编辑矢量文件，不虚构外部链接，不使用文字方案代替实际图像。
