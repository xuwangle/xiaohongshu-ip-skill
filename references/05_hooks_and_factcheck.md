# 阶段四核心纪律：事实查证与爆款钩子分镜（承自 `cy-carousel`）

视觉交给 AI 绘出呼吸感与吸引力，但**内容骨架、事实真实性与分镜节奏必须保持工程级严谨**。

## 一、核心红线（违反任一项直接判不合格）

1. **事实可回溯，零编造**：
   - 每个数字、年份、百分比、置信区间、法条编号都必须先回到 PDF/论文/官方文本核实，登记入 `research/事实表.md`（字段：`陈述 | 原文关键句 | 页码/出处 | 口径与限制 | 用于第几页`）。
   - 主语与口径必须精确：区分样本范围（如北卡州回顾性研究 vs 随机分组试验、摩托车直接数据 vs 电动自行车外推、WHO 推算 vs 交管登记），绝不把局部/单一结论夸大成全人类定律。
2. **图上禁止出现草稿口吻与冗长 URL**：
   - **严禁**将 `TODO`、`待核实`、`未取得官方原文`、`账号名` 占位符或大串 `https://doi.org/...` 印上图片或正式笔记正文（所有链接与完整文献统一写入 `来源.md` 与 `置顶评论.txt`）。
3. **只产文件、不自动发布**：
   - 所有流程只输出本地图片包、preview 预览与文案文件，绝不自行登录平台发布。
4. **开放授权与参照隐私保护**：
   - 如引用真实新闻图/历史图仅用公有领域或开放授权并记清许可；参照对标账号截图仅在本地分析，不向外传图床。

## 二、两种高转化分镜模板

### 模式 A：读书笔记 / 生活实用科普（推荐 8 页，适用《高性价比人生指南》类长拆解）
1. **`01-封面.png`（强反差钩子）**：极低成本 vs 极高回报（例如 `0元2秒 vs 100元5秒`、`几十块钱的小东西`）+ 权威等级/核心悬念 + IP 主角出镜。
2. **`02.png`（第一要点·成本与硬收益）**：小代价换大收益的直观双卡对照（大字箭头百分比 + 一句白话）。
3. **`03.png`（反常识盲区 / 常见致命误区）**：刺破普通人每天都在犯错的盲点（如第二排未系带占比、冬天居家一氧化碳占比），配 IP「惊讶/疑惑」反应。
4. **`04.png`（宏观尺度与诚实边界）**：坦诚交代样本边界与统计差异——越敢说“研究局限在哪里”，专业知识博主越可信。
5. **`05.png`（第二要点·痛点场景钩子）**：生活场景对错对比（`× 不算戴 vs ✓ 戴好扣紧`、`本分该花 vs 冤枉钱可拒`），配 IP 场景示范。
6. **`06.png`（权威论文 / 法律条文拆解）**：OR/CI 硬证据拆解或精确法条清单（条目拆成可读 3 卡）。
7. **`07.png`（实操对照与适用边界）**：普通人能做/不能碰清单，清晰给出理性底线。
8. **`08.png`（行动清单 + 评论区钩子）**：带走 `2~3` 步今日就能做的动作 + 一句低门槛互动问题，配 IP「加油」立绘收尾。

### 模式 B：单篇论文 / AI 产品 / 科技概念深拆（10 页，承自 `cy-carousel` 经典节奏）
1. **封面**：反差或反常识双行标题 + 核心数字/矛盾点 + IP 引导；
2. **02–03 页（看得懂的大例子）**：把抽象论文还原成一个普通人能看懂的真实实验/历史现场；
3. **04–05 页（原理解剖 / 实验证据）**：提炼核心机理与关键实验数据对比图；
4. **06–07 页（一句白话定义 + 公式拆解）**：给出读者能转述给朋友的准确定义与边界；
5. **08–09 页（三条编号思考 + 局限提醒）**：不跟风吹捧，给出冷静判断维度；
6. **10 页（收尾金句 + 延伸讨论）**：引导收藏与评论讨论。

## 三、交付包文稿规范（缺一不可）

每次图文产出目录下必须包含以下独立非空文件，且统一以 **UTF-8 with BOM + CRLF** 编码（确保 Windows 记事本、WPS 直接双击打开无乱码）：
- `01-封面.png` ～ `0N.png`（全部 `1440×1920` 3:4 PNG）
- `全套预览.jpg`（4 列网格预览图）
- `标题.txt`（3–4 个高点击备选标题，突出冲突、数字与获得感）
- `正文.txt`（分条清晰、可直接复制到小红书/抖音正文框与话题标签）
- `置顶评论.txt`（核心出处来源核对 + 一手文献列表 + 引导评论互动话术）
- `来源.md`（原书页码/PDF 页码、原始 DOI/官方法规链接与口径备注）
- `交付简介.txt`（通俗版文件与每页内容速览）
- `交付清单.json`（含页序、尺寸、使用字体、生图方式与文件 SHA256 校验和）
