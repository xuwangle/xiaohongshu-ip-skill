# 阶段四：暖米彩铅视觉系统与个人 IP 融入规范

本规范取代旧版暗底/毛笔代码拼接渲染，专为小红书与抖音高点击率、高收藏率知识图文优化。

## 一、统一视觉系统（暖米白 + 深墨绿 + 彩铅纸感）

| 视觉角色 | 推荐色值 | 用途说明 |
| --- | --- | --- |
| 暖米白纸底 | `#F5F1E8` / `#FFF3DD` | 全图背景底纸，带轻微自然纸张纤维肌理（禁止纯白刺眼或暗黑底+大面积荧光蓝） |
| 奶油卡片底 | `#FCF9F2` | 信息卡片底色，配细线条边框 `#E7E1D5` 或淡青/淡橙点缀 |
| 深墨绿主字 | `#253B38` | 主标题、核心结论与强加粗关键字 |
| 青绿色强调 | `#27877B` / 浅背景 `#DCECE8` | 正向收益、重点步骤、正确操作与标签胶囊 |
| 暖琥珀橙强调 | `#E5A45B` | 关键对比数字、成本金额、数据大字 highlight |
| 陶土红辅助 | `#D96B5B` | 误区警示、禁止项、反常识盲区数字 |
| 脚标与正文灰 | `#58615D` / `#65706A` | 正文与左下/右下统一角标 |

### 排版与版面规范
- **现代无衬线字体**：所有画面中文均为苹果风现代黑体排版（如 **MiSans Global / 思源黑体 CN**），禁止毛笔书法字、浮雕厚黑阴影和艺术字变形。
- **单页克制密度**：每张竖版 `3:4` 卡片仅承载 `1` 个核心论点或 `1` 组对比数据；标题简短醒目（手机缩略图一眼看清），不把大段论文或密集网址直接贴进图片。
- **底部 6% 安全空白**：生图提示词中明确要求底部 `6%` 保持纯净米白纸底不放正文与水印，由 `scripts/postprocess.py` 统一用 `1440×1920` 清晰矢量字体叠加左下书名/主题、右下章节读书笔记。

## 二、个人 IP（如「阿乐」）融入规则

当工作流启用个人 IP 陪读时：
1. **必喂参考图**：每次调用生图工具均显式附上基准图与表情图（如 `02_IP特征说明.png`、`03_标准三视图.png`、`07_表情设定.png`），并把 `角色规范.md` 里的固定穿搭、比例与非对称细节写进 Prompt。
2. **三类标准出镜位**（不要每页硬塞全身大图，留足数据呼吸感）：
   - **01 封面主视觉**：主角全身或半身做出与主题强关联的动作/持道具姿态（如系安全带、手持报警器），搭配 `阿乐复学日记` 或账号签名。
   - **中段痛点 / 反常识页**：用圆形气泡头像或角落半身贴纸呈现对应表情（如听到睡觉火灾用「惊讶」、看推销陷阱用「疑惑」、看边界提醒用「认真/思考」）。
   - **08 行动清单 / 互动封底**：主角全身「加油」或比赞收尾，强化账号持续更新的系列品牌记忆。

## 三、字体授权与本地优先加载策略

1. 随仓库开源分发的仅限 **SIL OFL 1.1 开源思源黑体 CN**（`assets/fonts/SourceHanSansCN/SourceHanSansCN-VF.otf`）。
2. 若用户本机已从小米官网自行安装 **MiSans Global**（`https://hyperos.mi.com/font/download`），`postprocess.py` 自动优先加载 `MiSans-Medium` / `MiSans VF` / `MiSans-Bold`；若未安装则直接使用随仓 `SourceHanSansCN-VF.otf`，保证跨平台零报错且 100% 遵守字体许可。

## 四、生图自检与当场修复铁律（必做！）

1. **逐张看图验收**：AI 生图工具偶有汉字重字（如“直直”“人人”）、漏字（如“管道和表”漏掉“和”）、小徽章乱字或角色腕表左右镜像错误。
2. **先自修、后交付**：Agent 必须在内部用视觉工具逐张读图核验；发现任何错字、多字、漏字或非对称崩坏，**当场局部修图或重生成修复，确认干净后再运行 `postprocess.py` 与 `check_delivery.py`**，绝不带着已知错误交付给用户。
