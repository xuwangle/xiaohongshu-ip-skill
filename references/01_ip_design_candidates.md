# 阶段一：人物照片 → 6 款个人 IP 角色候选方案

根据用户上传的人物照片，设计 **6 个可供筛选的个人 IP 角色方案**。优先按要求调用 `Seedream 5.5`；若当前工作环境未提供 `Seedream 5.5` 工具或接口，**必须如实向用户说明环境实际情况，征得同意后再使用替代生图引擎，不得静默替换**。

## 一、区分参考图片的作用

如果同时上传人物照片和风格参考图：
- **人物照片**：用于提取长相、身份特征、穿搭和配色。
- **风格参考图**：用于理解线条、阴影、细节密度和画面质感。

**严禁**照搬风格参考图中的人物、发色、五官符号、服装、配饰或道具。  
如果有多张人物照片，以用户指定的照片或最新明确用于设计的照片为主要依据。

## 二、开始前一次性确认偏好

如果用户已经提供过以下信息，直接沿用，不重复提问；若尚未提供，**一次性**询问以下 5 题，等待回答后再生成：

1. **希望角色给人的第一印象是什么？**  
   可以选 2—3 个词，例如：松弛、机灵、温柔、亲切、有趣、酷、古灵精怪。
2. **希望角色与真人有多像？**  
   - A. 尽量保留本人辨识度。
   - B. 能看出是本人，可以明显卡通化。
   - C. 大胆改造，保留几个代表性特征即可。
3. **希望角色呈现什么年龄感和 Q 版程度？**  
   - 年龄感：儿童感、少年少女感、年轻成年人感、保留照片气质。  
   - Q 版程度：轻度、中度、高度。  
   *注：年龄感与 Q 版程度分别理解，不要因为头大身体小就自动画成婴幼儿。*
4. **有什么特别想保留或融入的个人符号？**  
   例如发型、眼镜、痣、标志性穿搭。可以跳过，也可以由 Agent 从照片中发现。
5. **有什么明确不喜欢、希望避开的设计？**

每题都可以回答“由你决定”。回答后其余设计判断自主完成，**不再继续追问**，不询问职业、内容领域或用途，也不提前要求用户选定具体五官画法。

## 三、先分析照片，再决定如何设计

从具体照片中提取 **3—5 个真正有辨识度的特征**，不仅列部件，还要观察结构关系：
- 头发与脸部的大小关系；
- 发型外轮廓、刘海分组、发际线和碎发位置；
- 脸型最宽处、脸颊转折和下巴轮廓；
- 眉眼、鼻子、嘴巴的形态、间距与位置关系；
- 人物神态、肩颈与衣身形成的整体感觉。

区分三类特征并整理成容易记住、容易重复绘制的几何形态与比例关系（不要逐根复制头发、逐条描摹衣褶，也不要套用通用漂亮漫画脸）：
- **主要辨识点**：需要转化为角色的核心记忆点；
- **辅助特征**：帮助保留本人气质；
- **偶然细节**：可以省略，不必照搬。

## 四、设计 6 个完整的人物方案

- 六款使用**同一种画风**，表现**同一个人的六种结构化角色设计可能性**（如不同 Q 版头身、简化取舍、五官几何、记忆符号强化）。
- 如果差异只是同一张通用漫画脸的微调，必须重新设计人物结构，不能靠堆砌装饰掩盖。
- 默认优先推荐适配「暖米纸底 + 细铅笔彩铅质感」的方案，方便无缝衔接后续全案与图文制作。
